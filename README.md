# Password Strength Checker
## Project Description
The Password Strength Checker is a Python-based cybersecurity project designed to evaluate password strength using different security parameters.
It checks password length, uppercase letters, lowercase letters, numbers, and special characters.
## Features
- Checks password length.
- Identifies uppercase and lowercase letters.
- Detects numeric characters.
- Checks special characters.
- Classifies passwords as Weak, Moderate, or Strong.
- Provides suggestions for improving password strength.
- Hides password input in the terminal.
## Technologies Used
- Python
- Regular Expressions
- Getpass Module
## Installation and Execution
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:
    python password_checker.py
## Password Evaluation Criteria
| Criteria | Score |:
| Minimum 8 characters | 1 |
| Uppercase letter | 1 |
| Lowercase letter | 1 |
| Number | 1 |
| Special character | 1 |
## Strength Classification
- 0–2: Weak
- 3–4: Moderate
- 5: Strong
